Vice Cover Studio turns a photo and a caption into GTA-style cover art: a dense multi-panel poster with a Vice City sunset or neon colour grade, bold caption lettering, a LEONIDA badge, a mission strip and a small Leonida map inset. Four procedural demo scenes (boulevard, neon pier, skyline, beach) are painted in code, so the app works with no photo files at all. It runs fully offline in a desktop browser; photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — load up to four photos (or use the built-in demo photos), pick a layout and a colour grade, write the caption, drag each photo to position it, scroll to zoom, and export a 1080 x 1080, 1080 x 1350 or 1920 x 1080 PNG.
